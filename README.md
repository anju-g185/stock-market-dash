Stock Market Analysis Dashboard

This project is an interactive Stock Market Analysis Dashboard built using Power BI, designed to analyze stock price movements, trading volume, technical trends, risk, and returns for major companies including TCS, Reliance, Infosys, ICICI Bank, and HDFC Bank.

The dashboard provides a comprehensive view of stock-market performance from 2021 to 2025 through interactive visualizations and key performance indicators.

Key Features
Stock Price Analysis: Tracks stock closing prices across different years and companies.
Average Stock Price: Displays the overall average stock price along with highest and lowest values.
Trading Volume Analysis: Examines trading volume trends and volume ranges over time.
Technical Analysis: Compares Closing Price with 20-day Moving Average (MA20), 50-day Moving Average (MA50), and 200-day Moving Average (MA200).
Daily Return Analysis: Visualizes yearly daily-return trends to understand price performance.
Risk & Return Analysis: Evaluates Total Return, Volatility, Maximum Drawdown, and Sharpe Ratio for the selected companies.
Interactive Filters: Users can filter the dashboard by company to analyze individual stock performance.
Key Metrics

The dashboard includes important KPIs such as Average Price, Highest Price, Lowest Price, Average Return, Average Volume, Total Return, Volatility, Maximum Drawdown, and Sharpe Ratio.

Tools & Technologies

Python | Pandas | NumPy | Power BI | Data Visualization | Financial Analysis

Project Objective

The primary objective of this project is to transform historical stock-market data into an interactive analytical dashboard that helps users understand price trends, trading activity, technical indicators, risk, and investment performance through data-driven visualizations.

This project demonstrates practical skills in data cleaning, exploratory data analysis, financial metrics, dashboard development, and business intelligence using Power BI.
